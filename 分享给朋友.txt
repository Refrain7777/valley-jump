让朋友用电脑浏览器或手机玩「山谷跳跃」
========================================

这个游戏是 Python 写的，要先打成网页，朋友才能用浏览器打开。

第一步：你自己打包（必须用系统黑窗口，不要用 Cursor 终端）
------------------------------------------------
1. 键盘 Win + R，输入 cmd，回车
2. 输入下面两行，每行回车：

cd /d D:\Py_Cursor
pack_web.bat

3. 等它提示类似 http://localhost:8000
4. 你自己先用电脑浏览器打开这个地址试玩（横屏更好）


第二步：朋友怎么玩
------------------------------------------------
【和你在同一个 WiFi】例如在家、教室、宿舍
- 看你电脑的 IPv4 地址（cmd 里输入 ipconfig，找“无线局域网”的 IPv4）
- 把这个发给朋友：  http://你的IP:8000
  例如 http://192.168.1.8:8000
- 电脑浏览器、手机浏览器都可以打开
- 手机请横屏，用左下方向、右下「跳 / 攻」

【不在同一个网、在外地】
- 需要把打包结果放到网上（GitHub Pages、itch.io 等）才能得到一个谁都能点的链接
- 打包完成后，网页文件在： D:\Py_Cursor\build\web
- 你有 GitHub 的话告诉我，我可以帮你发成公开链接


注意
------------------------------------------------
- 打包期间不要关那个黑窗口，关掉朋友就打不开了（局域网这种方式）
- 电脑防火墙如果拦了，允许 Python 访问网络
- 请用英文输入法；手机点屏幕按钮即可

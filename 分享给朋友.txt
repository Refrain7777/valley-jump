让朋友用电脑浏览器或手机玩「山谷跳跃」
========================================

在线地址（谁都可以打开）：
https://refrain7777.github.io/valley-jump/

请让朋友用系统浏览器打开，不要用微信里直接点开。
微信内置浏览器经常加载失败或一直转圈。
请点右上角，选择「在浏览器中打开」或「在 Safari / Chrome 中打开」。

第一次打开要下载大约 22MB 的游戏引擎（压缩后传输大约 10MB），
页面会显示中文进度和百分比。请等到进入开始画面再玩。
下载过一次之后，同一个浏览器再打开会快很多。

手机请横屏。左边是方向，右下是「跳 / 攻」，右上是「商店」。


如果还没发布、只在自己电脑上试
------------------------------------------------
这个游戏是 Python 写的，要先打成网页，朋友才能用浏览器打开。

第一步：你自己打包（必须用系统黑窗口，不要用 Cursor 终端）
------------------------------------------------
1. 键盘 Win + R，输入 cmd，回车
2. 输入下面两行，每行回车：

cd /d D:\Py_Cursor
pack_web.bat

3. 等它提示类似 http://localhost:8000
4. 你自己先用电脑浏览器打开这个地址试玩（横屏更好）


第二步：和你在同一个 WiFi 的朋友怎么玩
------------------------------------------------
例如在家、教室、宿舍
- 看你电脑的 IPv4 地址（cmd 里输入 ipconfig，找“无线局域网”的 IPv4）
- 把这个发给朋友：  http://你的IP:8000
  例如 http://192.168.1.8:8000
- 电脑浏览器、手机浏览器都可以打开
- 同样不要用微信内置浏览器
- 手机请横屏，用左下方向、右下「跳 / 攻」


注意
------------------------------------------------
- 局域网这种方式，打包期间不要关那个黑窗口，关掉朋友就打不开了
- 电脑防火墙如果拦了，允许 Python 访问网络
- 请用英文输入法；手机点屏幕按钮即可
- 已经发布到 GitHub Pages 时，直接发上面的在线地址，不必开着自己的电脑
